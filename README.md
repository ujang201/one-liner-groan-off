# One-Liner Groan-Off

A single original one-line dad joke for the make.fun bounty
"The One-Liner Groan-Off".

## The joke

> I told the vacuum it was sucking at its job — it said thanks, that's literally the job description.

## How it works

`main.ts` is a small deterministic program (no randomness, no clock, no
network, no input). It writes the joke above to `/output/entry.txt`
(or to `$OUTPUT_DIR/entry.txt` when that variable is set), one line of
under 140 characters, ready for the judge.

## Run

```sh
node main.ts
```
